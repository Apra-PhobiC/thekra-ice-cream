THEKRA ICE CREAM — PREMIUM MENU

Upload every file in this folder to the ROOT of the GitHub Pages repository.
Do not upload the ZIP itself.

The menu is responsive for phone portrait, phone landscape and tablet landscape.
No ordering controls are included.

To change the weekly flavor, edit the `flavors` array in index.html and replace the image filename/name/Arabic text.
Prices:
Flavors: Cone Biscuit SAR 5, Small SAR 6, Medium SAR 8, Large SAR 11.
Milkshakes: SAR 12 each.
Pudding: Tiramisu SAR 15, Chocolate Pudding SAR 14.
